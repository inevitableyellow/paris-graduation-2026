Mastery project
Telemetry to Transmission
Override Detection and Classification Using CAN Signals
UMSI Exposition April 20, 2026 · 12–2 PM Michigan League

Commercial trucks use an Advanced Driver Assistance System called IQCruise to help drivers maintain fuel-efficient speeds — but drivers often override it by pressing the throttle or brake. The problem? The raw sensor data doesn't explain why.

This project built an end-to-end data pipeline that processes CAN bus signals from 11 trucks across 2 seasons — over 10,000 override events — and uses machine learning to automatically classify the root cause of each override into distinct driving scenarios, like hill compensation, aggressive passing, or high-speed closing. For the first time, fleet operators have a data-driven answer to why drivers override the system.
